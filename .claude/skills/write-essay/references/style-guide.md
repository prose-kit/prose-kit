# 风格指南

## 结构

### 开头
直入场景或前提。不铺垫、不框架、不引言。

范例：
- "他第一次看见那种鱼是在入行第三年。"
- "村子没有名字。三十七个男人，十九个女人，若干孩子。"
- "我反应慢。"

### 分段
- 用 `---` 分隔段落组。绝不用编号标题。

### 结尾
- 绝不总结全文观点
- 绝不说教或得出明确结论
- 用一个画面、一个问题、一个场景或一句对话向外打开

### 篇幅
- 范围：900–9700 字
- 甜区：2000–4000 字
- 让想法决定长度，不要凑字数

## 句法规则

### 必须做的
- 短句。句子片段完全可以。
- 对话驱动："他说：" / "她说：" 模式，大量使用
- 中文冒号 `：` 引语，不用引号 `「」` 或 `""`
- 口语化
- 通过重复和平行结构制造节奏
- 单行段落制造冲击力

### 绝不能做的（禁用清单）
- 绝不用过渡词：然而、因此、诚然、不过、总之、此外、另外、综上所述、事实上、值得注意的是
- 绝不用感叹号（！）
- 绝不用煽情套话：岁月如歌、时光荏苒、不经意间、蓦然回首、恍如隔世、如梦似幻
- 绝不用 markdown 格式：# 标题、**加粗**、列表、编号
- 绝不用 emoji
- 绝不用"仿佛"超过一次
- 绝不用"作为一个..."句式
- 绝不用段首"其实"
- 绝不用学术腔：笔者认为、在某种程度上、不可否认
- 绝不用"在这个XXX的时代"
- 绝不用 em dash（—）：用逗号、句号或分行代替

## 隐喻架构

### 核心模式
每篇散文有 **一个** 核心隐喻贯穿全文。隐喻不解释。读者要么自己看懂，要么感受到。

### 跨学科编织
自然地融入其他领域的概念，**不解释**：
- 金融、数学、生物、物理、历史...
- 知识应该像属于叙述者的，不像是查来的。

## 语气

### 叙事视角
- 多数用第三人称："他" 为视角人物
- 有些用第二人称做演讲体："你"
- 同一篇混用视角完全可以
- "我"可以出现，但只做旁观者/记录者

### 调性
- 用平淡口吻叙述毁灭性的观察
- 幽默是干的、结构性的，绝不表演
- 愤怒是冷的，不是热的
- 智慧是意外出现的，绝不刻意

## 标签格式
- 逗号分隔的英文词：`philosophy,finance,family`
- 每篇 3–5 个标签
