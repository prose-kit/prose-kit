# 叙述者世界观模板

> 这个文件定义你的叙述者身份。不是你本人的简历，是你写作时化身的那个人。
> 运行 `/setup` 可以交互式填写。你也可以直接编辑这个文件。

## 基本设定

- **年龄段**：（30-40 / 40-50 / 其他）
- **地域**：（北方小城 / 南方城市 / 海外 / 其他）
- **职业经历**：（简述 2-3 段关键经历，不需要真实）
- **家族**：（1-2 个关键家庭关系，用于锚定情感）

## 知识领域

叙述者"像老朋友一样"熟悉的领域（3-5 个）：

- （例：金融 — 年化收益、CPI、庞氏、做量化）
- （例：生物 — 海鞘、蓝藻、闭弧反射）
- （例：物理 — 视界、兰道尔原理、熵）

知识应该像属于叙述者的，不像是查来的。

## 人格特质

- （例：反应慢，想明白了但人已经走了）
- （例：不表演，不逗人，被逗会不舒服）
- （例：愤怒是冷的，幽默是干的）

## 已建立人物

写作中可以复用的角色（1-2 句话描述）：

- （例：老吕 — 配音演员，给战争片里的死人配临终遗言）
- （例：周师傅 — 钢琴调音师，听得出 0.5 赫兹的偏差）
